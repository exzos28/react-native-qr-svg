# Expo example

An Expo SDK app that uses `react-native-qr-svg` from this monorepo
(`workspace:*`, resolved from TypeScript sources by Metro). Runs in Expo Go,
in a development build and on the web.

From the repository root:

```sh
yarn
yarn workspace expo-example start        # Expo Go / dev client
yarn workspace expo-example web          # in the browser
yarn workspace expo-example ios          # or: android — prebuild, build, install
```

`ios/` and `android/` are generated by `expo prebuild` and are not committed.

`yarn workspace expo-example test` runs the integration test in
`src/__tests__` with `jest-expo`.
